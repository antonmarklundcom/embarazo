# Prompts for Anton to paste into the Higgsfield UI himself

These are the slots where **Nano Banana Pro** is clearly the better tool and where it is free for you
in the UI. No Claude session may call a Nano Banana model (Anton's rule, 2026-09-20), so the prompts
live here instead.

They are written to be **pasted straight through, with nothing to substitute**: no
`<<<element_id>>>` placeholder (that syntax only resolves server-side during an MCP generation — by
hand it renders as literal text in the image), palette and style restated in full every time, and the
negative block at the end of each one.

Everything else is generated by S9 with `gpt_image_2_5` / sunburst — see `docs/imagery-brief.md`.

---

## Slot 3 — the 42 week size renders

**Why manual:** 42 images have to look like one illustrator drew them in one afternoon. Cross-image
consistency via a reference Element is exactly Nano Banana Pro's strength, and in the UI it costs you
nothing where it would cost 42 credits in-session.

**Output:** 1:1, 1024×1024 (2048 is fine, `webimg` downscales), one object per image, 42 images.

**File naming on the way back:** more than ten images, so save them in **week order** as `01.png`
… `42.png`. `01` is week 1 and `42` is week 42 — `webimg` maps number → `bebe-<n>.webp` → alt from
`docs/imagery-manifest.json`. Do not rely on download timestamps: if you reject and regenerate one
image it will sort last and the whole series lands on the wrong weeks silently.

### Step 1 — generate the reference image first

Generate **this one alone**, approve it, then register it as an Element and attach that Element to
every image in step 2.

> Warm flat editorial illustration of a single ripe banana, centred, filling about sixty percent of a
> square frame, seen straight on with a slight three-quarter tilt. Soft organic shapes, visible
> paper-grain texture, gentle hand-drawn line work with a slightly uneven ink edge. Flat lighting, no
> gradients beyond a single soft wash, no drop shadows, no reflections. Background a plain soft sand
> wash, colour #F8E2CB, with no border, no frame and no vignette. Palette strictly limited to: cream
> #FBF7F1, deep petrol green #2F5D50, terracotta #C96342, blush #F3DAD4, sky #D9E5EC, sage #DFE8D8,
> lavender #E6E0F0, sand #F8E2CB. Calm, warm, handmade, the look of a well-printed children's health
> booklet from Asunción. Square 1:1 composition with even margins on all four sides.
>
> Negative: photorealism, 3-D render, stock-photo look, glossy highlights, lens flare, hard shadows,
> gradients, navy blue, hot pink, neon, text, letters, numbers, watermarks, logos, UI elements,
> borders, frames, people, hands, fetus, baby, anatomy, medical equipment.
