# embarazo.com.py

The SEO + conversion site for **Mi Bebé**, the free pregnancy PWA made for Paraguay
(`https://app.embarazo.com.py`, repo `antonmarklundcom/embarazo.2.1`).

Static HTML + PHP from `antonmarklundcom/php-site-template`, built in phases by Claude Code
sessions. Start at `plan.md`. Facts about the app live in `docs/app-facts.md`.

Order of operations: merge the plan PR → run `prompts/opus-0-design-and-preview.md` in an Opus
session → merge its PR → paste `Read prompts/sonnet-0-adopt.md in this repo and execute it.` into
a fresh Sonnet window (permission mode auto-accept) → walk away. The link pass writes the real
README.
